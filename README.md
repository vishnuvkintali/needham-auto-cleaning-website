# Needham Auto Cleaning — Client Website

A fully live, professional website built for a real local car wash business in Needham, MA. Built from scratch with HTML, CSS, and JavaScript — no frameworks.

**Live site:** https://needhamautocleaning.com  
**Backup URL:** https://needham-auto-cleaning.netlify.app

## What I Built

A complete business website including:

- Services and pricing page
- Customer contact/booking form
- Owner announcements system (post updates from any device)
- Owner login dashboard (Firebase auth — password never in the code)
- Visitor analytics dashboard
- Before & after photo gallery
- Customer reviews section
- FAQ accordion
- Interactive location map
- Mobile-friendly responsive design
- "Closed for Season" and "Closed Temporarily" toggles for the owner

## Technology Stack

## How to Deploy

Drag the `output/` folder onto Netlify. One drag = live update.
